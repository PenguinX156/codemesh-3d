Deadline: Nov 4, 2026, 9:00 PM ET (22:00 machine-local, GMT-4).
Form: https://cerebralvalley.ai/e/meta-ai-developer-hackathon/hackathon/submit (user submits it themselves).

## Required fields
- Team Name
- Track: Indie Developer Track | Startups Track
- Problem statement: Build for Your World | Push the Frontier
- Project Description (≤ 3,000 chars)
- Public GitHub Repository (URL)
- 3-Minute Demo Video (URL) — organizers: "Showcasing your project well is critical in the judging process."
- Describe your use of Meta products (≤ 3,000 chars)
- Why are Meta's models important to your solution? (≤ 3,000 chars)
- How likely are you to build with Meta Model API? / Overall opinion of Meta Model API (multiple choice)

## Optional
- X post link (Most Viral Project bonus: most engagement on X by Nov 8, 11:59 PM ET)
- Partner-technology feedback (≤ 150 chars), survey questions

## Judging
- Indie: creativity, technical ambition, whether it works.
- Startup: technical execution, whether it holds up in production.
